Re² supplementary website — standalone package

Open index.html in a modern browser. All data needed by the page is embedded,
and every image/video used by its current controls is included locally.

If your browser restricts local video playback, serve this folder with any
static web server, for example:

    python3 -m http.server 8000

Then open http://127.0.0.1:8000/ in the browser.
